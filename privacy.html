Απορρήτου.

Η παρούσα ενημέρωση εξηγεί με απλό τρόπο ποια δεδομένα συλλέγονται μέσω του ιστοτόπου, γιατί χρησιμοποιούνται και ποια δικαιώματα έχετε.

1. Υπεύθυνος επεξεργασίας

Υπεύθυνος για την επεξεργασία των δεδομένων που υποβάλλονται μέσω του ιστοτόπου είναι η D.P. Accounting Solutions, με έδρα στα Τρίκαλα. Για κάθε θέμα προστασίας δεδομένων μπορείτε να επικοινωνείτε στο dpeconsolutions@gmail.com ή στο 24310 76222.

2. Ποια δεδομένα συλλέγουμε

Όταν χρησιμοποιείτε τη φόρμα επικοινωνίας μπορεί να συλλέξουμε ονοματεπώνυμο, email, τηλέφωνο, το αντικείμενο ενδιαφέροντος και το κείμενο του μηνύματός σας. Μην αποστέλλετε μέσω της αρχικής φόρμας φορολογικά στοιχεία, κωδικούς, ΑΦΜ, οικονομικά αρχεία ή άλλα ευαίσθητα έγγραφα.

Κατά την απλή επίσκεψη ενδέχεται οι τεχνικοί πάροχοι φιλοξενίας να καταγράφουν βασικά τεχνικά δεδομένα, όπως διεύθυνση IP, τύπο προγράμματος περιήγησης και χρόνο πρόσβασης, για λόγους ασφάλειας και λειτουργίας.

3. Σκοπός και νομική βάση

Τα στοιχεία της φόρμας χρησιμοποιούνται αποκλειστικά για να αξιολογήσουμε και να απαντήσουμε στο αίτημά σας, βάσει των προσυμβατικών ενεργειών που ζητάτε και του έννομου συμφέροντός μας για ασφαλή επαγγελματική επικοινωνία. Δεν χρησιμοποιούνται για αυτοματοποιημένη λήψη αποφάσεων και δεν πωλούνται.

4. Χρόνος διατήρησης

Τα αιτήματα επικοινωνίας διατηρούνται μόνο για όσο απαιτείται για την απάντηση και την ενδεχόμενη έναρξη συνεργασίας, ή για όσο επιβάλλεται από νόμιμη υποχρέωση. Αιτήματα που δεν οδηγούν σε συνεργασία διαγράφονται ή ανωνυμοποιούνται σε εύλογο χρονικό διάστημα.

5. Τεχνικοί πάροχοι

  • GitHub Pages: φιλοξενία και ασφαλής παράδοση του ιστοτόπου. Η GitHub αναφέρει ότι καταγράφει τη διεύθυνση IP επισκεπτών Pages για λόγους ασφάλειας.
  • FormSubmit: τεχνική διαβίβαση των στοιχείων της φόρμας στο email του γραφείου. Ισχύει η πολιτική του παρόχου.

Οι πάροχοι λειτουργούν με τους δικούς τους όρους και πολιτικές. Δεν χρησιμοποιούμε στον παρόντα ιστότοπο εξωτερικές γραμματοσειρές, διαφημιστικά cookies, trackers συμπεριφοράς ή live chat. Η επιλογή θέματος, όπου παρέχεται, αποθηκεύεται τοπικά στη συσκευή σας μέσω localStorage και δεν αποστέλλεται σε εμάς.

6. Ασφάλεια

Χρησιμοποιούμε σύνδεση HTTPS και περιορίζουμε τη συλλογή στα απολύτως αναγκαία στοιχεία. Καμία μετάδοση στο διαδίκτυο δεν μπορεί να θεωρηθεί απολύτως ασφαλής· γι’ αυτό δεν πρέπει να αποστέλλετε ευαίσθητα λογιστικά ή φορολογικά έγγραφα μέσω της δημόσιας φόρμας.

7. Τα δικαιώματά σας

Ανάλογα με τις προϋποθέσεις του ΓΚΠΔ, μπορείτε να ζητήσετε πρόσβαση, διόρθωση, διαγραφή, περιορισμό ή εναντίωση στην επεξεργασία και φορητότητα των δεδομένων σας. Μπορείτε επίσης να υποβάλετε καταγγελία στην Αρχή Προστασίας Δεδομένων Προσωπικού Χαρακτήρα.

Για την άσκηση δικαιώματος στείλτε μήνυμα στο dpeconsolutions@gmail.com με θέμα «Προσωπικά Δεδομένα».

8. Αλλαγές στην πολιτική

Η πολιτική μπορεί να ενημερώνεται όταν αλλάζουν οι λειτουργίες ή οι πάροχοι του ιστοτόπου. Η ημερομηνία της τελευταίας ενημέρωσης αναγράφεται στην αρχή της σελίδας.

Σημείωση

Το κείμενο αποτελεί λειτουργική ενημέρωση απορρήτου για τον παρόντα ιστότοπο και δεν υποκαθιστά εξατομικευμένη νομική γνωμοδότηση.
